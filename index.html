    把新的课表 JSON 粘贴到下面，或先点「导出当前数据」拿到格式模板，改好再粘贴导入。导入会覆盖当前课表并保存在本机浏览器。

    把工作台设为浏览器主页 🌸

    1. 在浏览器打开本页面地址（预览链接）。
    2. Chrome / Edge：设置 →「启动时」→ 选择「打开特定网页或一组网页」→ 添加本页面地址。
    3. 之后每次打开浏览器，就会直接看到最新的课表和待办。

    待办事项保存在浏览器本地（localStorage），换电脑或清缓存会清空；课表数据更新请用左下「导入新课表数据」。
